收券盒 · 支援

TicketBox · iOS / Android

「收券盒」把散落在相簿裡的優惠券、兌換券、電子票截圖集中起來，自動讀出到期日與兌換序號，快到期時提醒你。開發者沒有伺服器，你的截圖與票券內容不會經過我們。

常見問題

辨識出來的到期日或序號不對？

匯入時的確認頁會把讀不準的欄位用黃色標出來，可以直接修改；存好後也能在票券詳情頁按「編輯」修正。辨識結果僅供參考，請以票券原始內容為準。

兌換時店員掃不到條碼？

收券盒兌換時出示的就是你匯入的原始截圖（不壓縮、不重新產生條碼）。請先在兌換模式按「放大條碼」，並確認螢幕亮度已調到最亮；部分掃描器對螢幕反光較敏感，可稍微傾斜手機。若原始截圖本身條碼就不清楚，建議重新從原 App 截圖。

沒有收到到期提醒
  • 確認系統的通知權限已開啟，並在 App 的「設定 → 提醒」確認三個時段的開關。
  • 只有「使用中」且有到期日的票券會提醒；同一時間到期的券會合併成一則通知。

iOS設定 → 通知 → 收券盒 → 允許通知。

Android設定 → 應用程式 → 收券盒 → 通知。部分品牌手機的省電模式會延後通知，可把收券盒設為「不限制電池用量」。

相同的券匯入兩次會怎樣？

收券盒以兌換序號判斷是否重複；序號相同時會提示，並開啟已存的那一張讓你確認。

換手機怎麼搬資料？iPhone 和 Android 之間可以嗎？

在「設定 → 備份」按「匯出備份檔」，產生 .ticketbox 檔案（含票券、原始截圖與序號），在新手機的收券盒「匯入備份檔」即可。iPhone 與 Android 版使用同一種格式，可以互相匯入。

iOS同一個 Apple ID 的 iPhone、iPad 會透過你自己的 iCloud 自動同步。

AndroidGoogle 自動備份不包含原始截圖，換手機請務必使用備份檔。

備份檔含有可兌換的序號，分享給別人前請留意。

免費版和 Pro 差在哪？

免費版可存 20 張「使用中」的券（已使用、已過期不計），到期提醒、兌換模式、日曆、備份都免費。Pro 提供無上限收納、桌面小工具（iOS 另有鎖定畫面小工具）與 App 鎖。

如何取消訂閱、恢復購買？

iOS取消：設定 → Apple ID → 訂閱 → 收券盒。恢復購買：App 內「設定」或升級頁的「恢復購買」。

Android取消：Google Play → 付款和訂閱 → 訂閱。用同一個 Google 帳戶開啟 App 會自動還原購買，也可在「設定 → 重新整理購買狀態」手動重試。
